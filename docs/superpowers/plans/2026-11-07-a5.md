# A5 JSONL Logging and Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** PCAP 전체 분석을 owned Engine 결과와 실패 격리 JSONL 발행으로 연결한다.
**Architecture:** inspect는 I/O 없이 메타데이터/판정을 반환한다. 별도 publisher가 공통 Event를 만들고 EventLogger는 bounded ASCII JSONL을 file/ostream에 기록한다. CLI는 옵션과 기존 human rendering을 맡는다.
**Tech Stack:** C++20, nlohmann/json, POSIX create-new FD, GoogleTest, Ubuntu/WSL CMake/Ninja.
**Spec:** [승인 설계](../specs/2026-11-07-a5-design.md).
