# A6 Live IDS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** live Ethernet capture feeds the A5 Engine with safe interruption, truthful statistics and JSONL.
**Architecture:** Linux nonblocking RAII LivePcapSource + bounded poll; existing Engine remains sink-free. CLI shares packet/final publication between PCAP and live. main owns signal handlers.
**Tech Stack:** C++20, libpcap>=1.9.0, existing nlohmann/json/GoogleTest/Python3/WSL.
**Spec:** docs/superpowers/specs/2026-11-08-a6-design.md.

## Global Constraints

- A6 only; preserve225 A5 tests, no automatic commit/push, current folder; IPS A0-A8 -> user self-tests -> explicit AI direction.
- live Drop is simulated; no host firewall/interface changes; actual live tests only inside anonymous netns/veth.
- snaplen262144, promisc0, timeout100ms, immediate mode, selectable FD required, nonblocking reads; wait min(100ms, current required select timeout).
- log failure latches/reports once but continues until stop/count; no stdout human text with --log -; final flush/close authoritative.
- stopped is distinct from EOF/abort; live capture_complete=false and run_complete reflects requested successful processing stop.
