# A0 Implementation Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans. The user's A0 scope and repository instructions take precedence over generic skill workflows.

**Goal:** C++20 CLI, Linux 의존성 탐색, GoogleTest/CTest, 품질 도구와 CI의 최소 기반을 만든다.

**Architecture:** 작은 자유 함수가 인자 검증과 출력을 담당하고 실행 파일은 인자를 전달한다. 시스템 패키지만 탐색하며 패킷 처리 코드는 생성하지 않는다.

**Tech Stack:** Linux, C++20, CMake >= 3.22, Ninja, GCC/Clang, GoogleTest, libpcap, libnetfilter_queue, nlohmann/json, spdlog.

**Spec:** [IMPLEMENTATION_PLAN.md A0](../../../IMPLEMENTATION_PLAN.md), [PROJECT_SPEC.md](../../../PROJECT_SPEC.md), [CODING_STYLE.md](../../../CODING_STYLE.md).

## Global Constraints

- A0만 구현한다. 패킷 수집·파서, Flow, TCP, 룰, Inline, Python/AI/IPC는 구현하지 않는다.
- 사용자가 지정한 현재 프로젝트 루트에서 작업한다. 기존 문서 4개를 수정하지 않는다.
- 현재 폴더는 Git 저장소가 아니므로 worktree·자동 커밋은 적용하지 않는다.
- 대상은 Ubuntu 24.04 LTS 또는 호환 Linux다. Windows 지원을 추가하지 않는다.
- 의존성을 자동 다운로드하거나 도구 누락을 성공으로 처리하지 않는다.

## Review Focus

- 인자 누락, 알 수 없는 옵션, 빈 인자는 실패해야 한다.
- 도움말 뒤의 추가 인자를 조용히 무시하지 않아야 한다.
- 향후 단계의 모드가 실제 동작한 것처럼 보여서는 안 된다.
- stdout/stderr 및 프로세스 종료 코드가 의도대로 분리되어야 한다.
- 도구 또는 실행 파일이 없으면 테스트 통과로 기록하지 않아야 한다.
