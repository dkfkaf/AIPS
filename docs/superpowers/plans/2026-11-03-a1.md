# A1 Implementation Plan

**Goal:** libpcap 기반 오프라인 파일 읽기와 Ethernet/IPv4/TCP/UDP 안전 파싱, 메타데이터 출력을 작성한다.

**Scope:** A1만 진행한다. 2026-11-03 사용자가 A0를 보류하고 A1 구현을 명시적으로 지시했다. A0는 완료로 바꾸지 않는다. 빌드 환경 복구는 이번 범위에서 제외하며 실행하지 못한 검증은 미검증으로 기록한다.

**Spec:** PROJECT_SPEC.md F-01, IMPLEMENTATION_PLAN.md A1, CODING_STYLE.md 8절.

## Files and interfaces

- include/miniips/packet.hpp: 일시적 PacketEnvelope, ParsedPacket, TCP 메타데이터.
- include/miniips/packet_parser.hpp, src/packet_parser.cpp: ParseResult = variant<ParsedPacket, ParseError>; parse_packet(const PacketEnvelope&) noexcept.
- include/miniips/capture_source.hpp, src/pcap_source.cpp: read_pcap(path, callback). pcap_close를 unique_ptr deleter로 묶는다. 콜백의 뷰는 해당 호출 중에만 유효하다.
- src/cli.cpp, include/miniips/cli.hpp: 기존 도움말·버전 유지, --mode pcap --input PATH 지원. 인자 오류 2, 파일/출력 오류 1, EOF까지 분석 완료 0.
- CMakeLists.txt, tests/CMakeLists.txt: 기존 의존성·Linux 조건을 유지하고 새 소스·테스트를 연결한다.
- tests/fixtures/packet_fixtures.hpp, tests/pcap_fixture.hpp: 고정 바이트와 테스트 중 생성하는 PCAP. 원본 캡처 파일은 커밋하지 않는다.
- tests/test_packet_parser.cpp, tests/test_pcap_source.cpp, tests/test_cli_pcap.cpp: 필드·경계·파일·CLI 테스트.
- tests/fixture_writer.cpp, tests/check_pcap_cli.cmake: 실제 miniips 프로세스 통합 테스트.
- tests/test_cli.cpp, tests/check_cli.cmake: 예전 PCAP 미구현 검사를 PCAP 필수 인자 누락 검사로 갱신한다.
- README.md, docs/design-decisions.md, docs/known-limitations.md, docs/test-plan.md: 구현 범위·승인 예외·미검증 항목 반영.

## Decisions

- L2 Ethernet만 지원한다. IPv6, VLAN, fragment, 기타 IP 프로토콜은 원인별 오류로 구별한다.
- 바이트 단위 big-endian 읽기, caplen 기준 검사, IP Total Length로 Ethernet padding 제외.
- 비조각 UDP의 Length는 IP 페이로드 길이와 같아야 한다. 체크섬 검증은 제외한다.
- 나노초 PCAP도 libpcap에 마이크로초 정밀도로 요청한다. 음수·범위 초과 타임스탬프는 파일 오류다.
- snapshot/수신 레코드 상한은 262144 bytes다. 입력 "-"는 stdin 대기 방지를 위해 거부한다.
- 패킷 파싱 오류는 stderr 경고 후 다음 레코드 처리. 컨테이너 손상은 읽기를 중단하고 1로 종료.
- stdout에는 메타데이터와 분석 건수만 출력하며 원시 payload, 룰 verdict, A5 JSONL 이벤트는 생성하지 않는다.
- A2 Flow, A3 재조립, A4 룰, A6 live, A7 Inline, B/C AI·통신은 구현하지 않는다.
